# Guia de preenchimento do README

Este arquivo funciona como apoio para a equipe durante a atualização do `README.md`.

## Regra principal

Não deixe textos do modelo sem substituir. Sempre que houver um exemplo, adapte-o ao projeto real.

## Antes de entregar

1. Leia o README completo.
2. Verifique se todas as versões são reais.
3. Confirme se os diagramas representam a implementação atual.
4. Teste o passo a passo de instalação em uma máquina diferente, se possível.
5. Teste o passo a passo de execução.
6. Substitua figuras ilustrativas por screenshots reais.
7. Verifique se os links abrem corretamente.
8. Não publique senhas, tokens ou chaves privadas.

## Figuras

Use nomes simples e descritivos:

```text
docs/images/tela-inicial.png
docs/images/experiencia-ra.png
docs/diagrams/arquitetura.png
```

No README:

```markdown
![Tela inicial](docs/images/tela-inicial.png)
```

## Código

Evite colar arquivos inteiros no README. Explique a finalidade do código e aponte para o arquivo correspondente.

## Testes

Registre apenas testes realmente realizados. Não declare compatibilidade com dispositivos não testados.
